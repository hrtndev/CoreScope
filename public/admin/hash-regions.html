Hash Regions

MeshCore transport-scope names (e.g. #eu) the ingestor hashes with SHA-256 to derive HMAC keys for scope-matching on transport-route packets. Not related to the IATA display names on the Regions page.

Changes apply automatically — the ingestor re-checks this list roughly every 15 seconds and does not need to be restarted.
